# CatDog-Classifier
Feature extraction pipeline for cat vs. dog image classification on a subset of the Oxford-IIIT Pet Dataset (Abyssinian, Siamese, Boxer, Wheaten Terrier). Generates 19 feature bases with HOG and LBP across resolutions and parameters, plus PCA on the HOG bases. Coursework for IMD3002, Supervised Machine Learning (UFRN).
